## Install flexTri

Download the file for your computer below, then:

**Windows 10 or 11** — `flexTri-…-windows-setup.exe`
1. Double-click it. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**.
2. Click through the installer. flexTri opens in your browser when it finishes.
3. Next time, start it from the Start menu or the desktop icon.

**Mac** — `flexTri-…-macos-apple-silicon.dmg` (M1 or newer) or `…-macos-intel.dmg` (older Macs)
1. Open the .dmg and drag flexTri onto Applications.
2. Open flexTri from Applications. The first time, macOS blocks it: open **System Settings → Privacy & Security**,
   scroll down and click **Open Anyway**.

**Linux** — `flexTri-…-linux-x86_64.AppImage`
1. Right-click the file → Properties → allow running it as a program (or `chmod +x` it).
2. Double-click it.

flexTri runs on your computer only and opens at http://127.0.0.1:8000. Use **Quit** in the top right of the app
(or the flexTri icon in the taskbar / menu bar) to stop it. Your plan and check-ins are kept in your user folder
(`%LOCALAPPDATA%\flexTri`, `~/Library/Application Support/flexTri` or `~/.local/share/flextri`) and survive
updates: to update, install the new version over the old one.
